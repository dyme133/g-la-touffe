# G la touffe — prototype de présentation

Version de présentation Signature / Affiche du 26 septembre 2026 : accueil, salon, carte et informations pratiques.

Ce dépôt et son historique sont **publics**, conformément au choix confirmé pour ce prototype. La publication GitHub Pages sert uniquement à présenter cette proposition ; elle ne constitue pas un site officiel approuvé par le salon.

Le site contient uniquement les fichiers front-end, les médias retenus et les polices avec leur licence. Aucun dossier de recherche, rapport interne ou clé n'est inclus. Les versions précédentes restent récupérables dans l'historique Git.

Les photographies du salon sont des restaurations et élargissements génératifs Image 2 de la vidéo de présentation du salon. La vidéo portrait est conservée. La fidélité au lieu et les droits doivent être validés par le salon avant une utilisation officielle.

Le site garde une directive noindex pour les moteurs de recherche ; celle-ci n'est pas un contrôle d'accès. Les fichiers distribués au navigateur sont publics.
