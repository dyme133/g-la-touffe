# G la touffe — prototype de présentation

Copie figée de la proposition visuelle du 23 septembre 2026.

Ce dépôt et son historique sont **publics**, conformément au choix confirmé pour ce prototype. La publication GitHub Pages sert uniquement à présenter cette proposition ; elle ne constitue pas un site officiel approuvé par le salon.

Le site contient uniquement les fichiers front-end, les images retenues et les polices avec leur licence. Aucun dossier de recherche, rapport interne, clé ou historique de travail n'est inclus.

Les vues du salon sont des restaurations et élargissements génératifs Image 2 de la vidéo officielle de présentation du salon. La fidélité au lieu et les droits doivent être validés par le salon avant une utilisation officielle. Les crédits complets figurent dans la page.

Le site garde une directive noindex pour les moteurs de recherche ; celle-ci n'est pas un contrôle d'accès. Les fichiers distribués au navigateur sont publics.

Le second concept graphique est développé séparément et ne remplace pas cette version.
